# 2025-9444-Team1_MidProject

## RESERVATION SYSTEM FOR TERMINALS AND EQUIPMENTS

This system allows students to reserve computer terminals and equipment for study purposes, manage their reservations, and view their reservation history. Admins can manage the terminals and equipment (add, edit, remove), approve or reject student reservations, and generate reports.  

The system enforces reservation rules, such as a maximum usage of 2 hours per day and advance booking limitations. It features an MVC-based client-side application and a server-side system that handles data storage via JSON files instead of XML. The project has transitioned from socket programming to an RMI-based client-server structure, supporting multiple clients simultaneously. Additionally, improvements have been made to error handling, logical flow, and GUI design.

## UPDATES:
- Socket programming changed to RMI client-server structure  
- The use of JSON file instead of XML file  
- Fixed errors and revisions to logics and GUI
